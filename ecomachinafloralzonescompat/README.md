# Eco Machina x Floral Zones Compat (ecomachinafloralzones)

JSON patch mod (no C#). Lets Eco Machina's foliage treatment apply to Floral Zones Cape Region trees and the small Circumboreal white spruce, which generate with -placed- leaves that Eco Machina skips. Patches only apply when Eco Machina and the matching Floral Zones pack are loaded.

Note: the modid in modinfo.json is ecomachinafloralzones.

Credit:
- Eco Machina (vsecomachina) by Svend Richter.
- Floral Zones region packs by Flishster and Tenth Architect (Cape region also lists Heironymous).

This is a compat patch only; it contains none of their assets. NOTES-build.md is the original build session write-up; tools/ has the static check scripts (they expect local copies of the originals). Not tested in game at the time of writing. Not on ModDB.
